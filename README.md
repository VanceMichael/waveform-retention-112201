# 质量复核波形收件站

质量复核波形收件站的来源包括现场控制器、质量复核报工和工装台账。运行服务使用合成资料，可在本机独立回放。

使用 Node.js 22。执行 `npm ci` 安装锁定依赖。

运行 `npm start`，来源默认监听 `127.0.0.1:4180`，可用 `PORT` 指定端口。
`npm test` 启动一份独立来源实例并检查其真实响应。

来源契约见[接口说明](docs/sources.md)。业务方可提交的样例资料保存在 `inputs/`。
回放从第一刻度开始，向 `POST /clock` 提交 JSON 对象中的整数 `step` 推进。读取 `GET /clock` 可取得来源的刻度和业务时间。
每次重启来源服务都会新建一份回放。
